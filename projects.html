Project 01

AdeHair

Hair appointment booking · Frontend prototype

The idea

AdeHair explores a simpler way for independent hairstylists to manage appointments and communicate their availability. Instead of relying entirely on repeated WhatsApp conversations, the concept brings available time slots, booking options, and appointment status into one interface. It is designed around the needs of local hairstylists and customers who value a straightforward booking experience.

My contribution

  • Independently developed the interface concept and information architecture.
  • Built the frontend booking experience using HTML, CSS, and vanilla JavaScript.
  • Designed appointment states for availability, bookings, and cancellations.

Technologies

  • HTML
  • CSS
  • JavaScript

Status

Prototype. The frontend demonstrates the proposed booking experience. A live booking service and production deployment are not currently available.

Project 02

Zionix

Reading experience · Content-focused interface

The idea

Zionix explores how a carefully structured interface can make reading and navigating long-form content more comfortable. The design prioritises typography, readable line lengths, and clear navigation, reducing unnecessary interface elements that compete with the content. The goal is a focused reading experience that feels organised and easy to follow.

My contribution

  • Independently developed the interface concept and content structure.
  • Implemented a responsive reading layout using CSS Grid.
  • Built a lightweight reading-progress indicator with vanilla JavaScript.
  • Explored a restrained visual system for long-form content.

Technologies

  • HTML
  • CSS
  • JavaScript
  • Tailwind CSS (prototype exploration)

Status

Study project. Zionix documents an exploration of content-focused interface design and reading usability. It is presented as an independent development study rather than a deployed publication platform.

Project 03

Citicare

Healthcare information · Accessible frontend

The idea

Citicare focuses on making essential clinic information easier to access through a clear, lightweight web interface. The experience centres on helping visitors find relevant clinic details, check opening hours, and access contact information without navigating an unnecessarily complex website. The implementation considers accessibility, usability, and performance on slower connections and less powerful devices.

My contribution

  • Independently developed the frontend interface using React and TypeScript.
  • Implemented the styling system with Tailwind CSS and custom design tokens.
  • Worked on colour contrast, keyboard navigation, and interface accessibility.
  • Structured the interface around clear information hierarchy and usability.

Technologies

  • React
  • TypeScript
  • Tailwind CSS
  • HTML
  • CSS

Status

Frontend project. The project demonstrates the implementation of a healthcare information interface. A production deployment and live service are not claimed here.

Project 04

Ambassadors' Academy

Educational website · School information and admissions

The idea

Ambassadors' Academy is an educational website designed to present a school's identity, academic offerings, and admissions information through a structured online experience. The website brings together information about the school's history, Nigerian and British curricula, primary and secondary education, extracurricular activities, and admission requirements. Its navigation helps parents and prospective students explore the institution and find relevant information in one place.

My contribution

  • Independently built the website from concept through implementation.
  • Developed the page structure and navigation across the main website sections.
  • Implemented the academic programmes, admissions, gallery, and contact sections.
  • Built the interface using HTML, CSS, and vanilla JavaScript.

Technologies

  • HTML
  • CSS
  • JavaScript

Status

Completed · Live website. The website is deployed and publicly accessible. It demonstrates my ability to independently develop and deliver a multi-section educational website.

Project 05

BeCella Grocery Store

Grocery retail website · Product discovery and services

The idea

BeCella Grocery Store is a grocery retail website built to present products and shopping services through an accessible online storefront. The website features a range of grocery categories, including Nigerian food staples, fresh produce, beverages, household essentials, and personal care products. It also highlights services such as grocery delivery, specialty-item sourcing, recurring deliveries, and gift baskets, helping visitors explore the store's offerings and contact the business.

My contribution

  • Independently built the website from concept through implementation.
  • Structured the product categories and shopping information for easy browsing.
  • Developed the website sections covering the business, services, and contact information.
  • Implemented the storefront presentation and supporting content across the website.

Technologies

  • Technology stack not specified

Status

Completed · Live website. BeCella is deployed and publicly accessible. The project demonstrates my ability to independently build and deliver a multi-section website for a grocery retail business.
